## 🌟 About The Project

**Fine Lodges** is a simple and clean lodge booking website built using **HTML** and **CSS**. It allows users to view available lodges with their rent and book them online through a simple form.

> 🎯 A BCA Minor Project — Frontend (5th Semester)

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🏠 Home Page | Displays available lodges with images and rent |
| 💰 Rent Display | Shows rent per person for each lodge |
| 📝 Booking Form | Simple form to book a lodge |
| 🎨 Clean UI | Orange and white theme — simple and attractive |
| 📱 Responsive | Works on mobile and desktop |

## 🗣️ Project Explanation

> This is a **Lodge Booking System** built with HTML and CSS. The home page displays two lodges — **Radheshyam Lodge** (₹1500/person) and **Chattri Lodge** (₹1700/person) — with their images and rent. When the user clicks **Book Now**, a booking form opens where they can fill in their details and confirm the booking.
