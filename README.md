# Fine Lodges

A simple lodge booking website built with HTML and CSS.

## About

Fine Lodges is a frontend web project that allows users to view available lodges and book them online. This project is created as a minor project for BCA 5th semester.

## Features

- Home page with two lodges
- Lodge images with rent details
- Book Now button for each lodge
- Booking form page
- Simple and clean orange and white theme

## Lodges Available

| Lodge Name | Rent |
|------------|------|
| Radheshyam Lodge | 1500 per person |
| Chattri Lodge | 1700 per person |

## Pages

- index.html - Home page
- booking.html - Booking form

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Download or clone this repository
2. Open index.html in any web browser
3. Click on Book Now to open the booking form
